## 프로젝트 상세
![010](./img/010.png)
1. **개요** : 설치시운전에 대한 기본적인 내용 및 요약, 납품 목록을 입력합니다. 
1. **프리미팅** : 위탁한 도비사 담당자가 입력하는 탭 입니다. 도비사 담당자는 설치시운전 **자료 제출 페이지** 링크를 문자로 받을 수 있습니다.
   <br/>설치시운전을 위해 고객과 진행한 프리미팅 내용이 입력됩니다.
1. **설치** : 위탁한 도비사 담당자가 입력하는 탭입니다. 설치시운전에 대한 상세한 내용을 등록할 수 있습니다. 
<br/>
<br/>

## (본사)프리미팅 자료 제출
![032](./img/032.png)
<br/> 도비사에서 진행하는 프리미팅 내역을 등록하고, 본사에서 확인 할 수 있는 탭 입니다. 

1. 프리미팅 탭을 클릭합니다. 
:::warning
도비사에서 프리미팅 내역을 입력하기 전 인 경우, 그림과 같이 "**담당자가 자료를 제출하지 않았습니다.**" 라는 문구가 표시됩니다. 
<br/> **개요** 탭에서 도비사 담당자에게 프리미팅 제출 문자를 재전송 할 수 있습니다. 
:::
<br/>
<br/>

### 자료 제출 문자 발송
![031](./img/031.png)
설치시운전 프로젝트가 생성되면, 프로젝트 담당자들에게 관련 문자가 발송됩니다.
<br/>프리미팅 및 설치 관련 자료 제출 문자를 받지 못한 경우, 문자 재전송이 가능합니다.

1. 자료 제출 페이지 링크를 재설정 할 수 있습니다. 
1. **재전송** 버튼 클릭 시 담당자에게 문자가 재전송됩니다.  
<br/>
<br/>

## (도비사)프리미팅 자료 제출
:::info
    **도비사 담당자**는 문자로 받은 링크에 접속하여 프리미팅 자료를 제출해야 합니다.
:::

<div><img src={Mobile1} width="30%" alt="033"/></div>

1. 프로젝트의 기본 정보 확인이 가능합니다. 
    :::info
    프로젝트 No., 고객사 명, 고객사 주소, 고객사 검수 담당자 명, 담당자 연락처, 출하 예정일을 확인 할 수 있습니다.
    :::
1. 프리미팅 탭을 클릭합니다. 
<br/>
<br/>

<div><img src={Mobile2} width="30%" alt="034"/></div>

1. 토글 버튼을 클릭합니다. 
<br/>
<br/>

<div><img src={Mobile3} width="30%" alt="035"/></div>

<br/>프리미팅 입력창이 활성화되면, 관련 정보를 입력할 수 있는 항목이 나타납니다.

1. 프리미팅 시작 시간을 선택합니다. 
1. 프리미팅 종료 시간을 선택합니다. 
1. 중량물 취급 작업계획서를 등록합니다. 
<br/>
<br/>

<div><img src={Mobile4} width="30%" alt="036"/></div>

1. 제출 버튼을 클릭합니다. 
    :::info
    <div><img src={Mobile5} width="40%" alt="037"/></div>

    1. **확인** 버튼을 클릭하여야 최종 제출이 완료됩니다. 
    <br/>제출이 완료되면 본사 담당자에게 확인 요청 메일이 발송됩니다.
    :::
<br/>
<br/>

## (본사)프리미팅 보완 요청
:::info
프리미팅 자료 제출이 완료되면 본사 담당자는 프리미팅 내역을 확인하고 "확인완료" 처리를 해야합니다.
:::
![038](./img/038.png)
1. 프리미팅 자료의 보완이 필요한 경우 "보완 요청" 버튼을 클릭합니다. 
<br/>
<br/>
<div><img src={Popup1} width="50%" alt="039"/></div>

1. 프리미팅 자료 제출 담당자에게 전달할 보완 요청 사유를 작성합니다. 
1. **확인** 버튼을 클릭하여 보완 요청을 진행합니다. 
    :::info
    프리미팅 담당자에게 보완 요청 문자가 전송됩니다. 
    :::
<br/>
<br/>

![040](./img/040.png)
<br/>프리미팅 탭에서 다음과같이 보완 요청에 대한 내용을 확인 할 수 있습니다.

1. 보완 요청을 취고하고자 할 경우 **보완 취소** 버튼을 클릭힙니다. 
<br/>보완 취소 시 프리미팅 확인완료 처리를 할 수 있습니다.
<br/>
<br/>

## 공통내용
![026](./img/026.png)
:::info
    프로젝트 상세 화면에서 각 탭에 공통으로 들어가는 내용입니다. 공통내용에 들어가는 각 항목은 하단의 내용을 참조해주세요.
:::
<br/>
<br/>

### 기본정보/설치시운전 보고서/파일
![027](./img/027.png)
1. 설치시운전 프로젝트의 코드를 확인 할 수 있습니다.
1. **설치시운전 보고서**가 추가 될 예정입니다.
1. 프로젝트에 참고할만한 첨부파일을 추가할 수 있습니다.
<br/>
<br/>

### 고객사/고객사 검수 담당자
![028](./img/028.png)
1. 고객사 정보를 확인하고, 수정이 필요한 경우 **수정** 버튼을 클릭합니다. 
1. 고객사 검수 담당자의 변경이 필요한 경우 **변경** 버튼을 클릭합니다. 
<br/>
<br/>

### 담당 센터/관리자/활동/코멘트
![029](./img/029.png)
1. 담당 센터의 경우, 프로젝트 생성 이후 변경이 불가합니다. 
1. **추가** 버튼을 클릭하여 프로젝트 관리자를 추가할 수 있습니다.
1. 프로젝트의 활동 내역을 타임라인으로 확인 할 수 있습니다. 
1. 코멘트 작성으로 엔지니어 및 관리자간 소통을 할 수 있습니다. 
    :::info
    <div><img src={PopUp6} width="50%" alt="030"/></div>
    1. 코멘트 내용을 입력합니다. 
    1. **중요(알림 발송)**을 체크한 경우, 관련자들에게 문자 알림이 발송됩니다.
    1. 버튼을 클릭하여 코멘트 작성을 완료합니다. 
    :::
1. 프로젝트를 취소해야 할 경우 사용합니다. 설치시운전 작업이 완료되면 버튼이 비활성화 됩니다. 
1. **즐겨찾기**를 선택 할 수 있습니다.
