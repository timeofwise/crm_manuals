# 툴링 및 샘플 제작

고객사의 툴링 및 샘플 제작 요청을 등록하고 관리하는 방법을 안내합니다. 
<ValidateTextByToken dispTargetViewer={true} dispCaution={false} validTokenList={['head', 'branch']}>

## 신규 등록
![011](./img/011.png)
1. **툴링 및 샘플 제작** 메뉴를 클릭합니다. 
1. **+** 버튼을 클릭합니다. 
<br/>
<br/> 

### 기본정보
![012](./img/012.png)
1. **툴링** 및 **샘플제작** 중 해당하는 항목을 선택합니다. 
1. 고객사에게 요청받은 내용을 자세히 작성합니다. 
1. **희망 납기일**을 입력합니다. 
<br/>
<br/>

### 요청센터
![013](./img/013.png)
1. **요청센터**를 선택합니다.
    :::info
    회사명은 사용자의 회사가 자동 입력됩니다. 변경이 필요할 경우에만 **선택** 버튼을 눌러 수정합니다.
    :::
1. **요청자**를 선택합니다.
<br/>
<br/>

### 고객사 정보
![014](./img/014.png)
1. **고객사**를 선택합니다. 
1. **고객사 담당자**를 선택합니다. 
1. **주소**를 선택합니다. 만약, 해당하는 주소가 없을 경우 추가합니다. 
<br/>
<br/>

### 가공품
![015](./img/015.png)
1. **+** 버튼을 클릭하여 가공품을 등록합니다. 
<br/>
<br/>

### 첨부파일
![016](./img/016.png)
1. **추가**버튼을 클릭하여 도면 등의 정보를 추가합니다. 
    :::info
    첨부파일은 수정이 불가능하므로 필요한 정보를 충분히 등록하도록 합니다.
    :::
<br/>
<br/>

### 접수
![017](./img/017.png)
1. **접수**를 클릭하여 완료합니다. 
<br/>
<br/>

## 접수 처리
![018](./img/018.png)
:::info
접수가 완료된 기술지원은 세 개 탭을 확인 할 수 있습니다. 
:::
1. **개요** : 접수 시 등록된 각종 정보를 확인 할 수 있습니다. 
1. **툴링 및 샘플** : 기술지원 내역을 등록할 수 있습니다. 
1. **정산** : 툴링 및 샘플 기술지원이 완료된 경우에 사용이 가능합니다. 작업에 소요된 비용 내역을 등록하여 관리할 수 있습니다. 
<br/>
<br/>

### 개요 - 기본정보
![019](./img/019.png)
1. 기본정보는 **수정**이 가능합니다. 필요 시 **수정** 버튼을 클릭하여 수행합니다. 
<br/>
<br/>

### 개요 - 가공품
![020](./img/020.png)
1. 가공품은 **수정**이 가능합니다. 필요 시 삭제 또는 추가 버튼을 클릭하여 수행합니다. 
<br/>
<br/>

### 개요 - 첨부파일
![021](./img/021.png)
<br/>첨부파일은 수정이 불가능하며, 클릭하여 다운로드 할 수 있습니다. 
<br/>
<br/>

### 툴링 및 샘플 - 담당자 배정
![022](./img/022.png)
1. **기술지원 담당자**를 선택합니다.
    :::info
    ![023](./img/023.png)
    1. 담당자 배정 후에는 담당자에게 문자 및 이메일로 알림이 발송됨을 유의하여 **확인** 버튼을 클릭합니다. 
    :::
1. 접수 시 등록된 희망 납기일이나 완료 예정일의 수정이 필요한 경우, **수정**을 클릭하여 수행합니다.

### 툴링 및 샘플 - 구매
:::warning
**기술지원 담당자**를 선택해야만 **구매** 작성란이 나타납니다. 
:::
<div><img src={Purchase1} width="70%" alt="025"/></div>

1. **+**버튼을 클릭합니다. 
<br/>
<br/>

![026](./img/026.png)
1. 구매 담당자 이름을 검색합니다. 
1. **저장** 버튼을 클릭합니다.
<br/>
<br/>

<div><img src={Purchase2} width="70%" alt="027"/></div>

1. 구매 요청 및 입고 내역 추가를 위해 **+** 버튼을 클릭합니다.
<br/>
<br/>

<div><img src={Popup2} width="60%" alt="028"/></div>

1. **구매 요청일**을 선택합니다. 
1. **입고 예정일**을 선택합니다.
1. **비고**에 참고 내역을 입력합니다. 
1. **입고여부**를 선택합니다. 
1. **첨부파일**을 추가합니다. 
1. **저장** 버튼을 클릭하여 구매내역 추가를 완료합니다.
<br/>
<br/>

### 툴링 및 샘플 - 프로그램
<div><img src={Program1} width="70%" alt="029"/></div>

1. 작성된 프로그램을 추가합니다. 
<br/>
<br/>

### 툴링 및 샘플 - 가공
:::info
최소 1개 이상 가공이 있어야 기술지원을 완료할 수 있습니다.
:::
<div><img src={Tooling1} width="70%" alt="030"/></div>

1. 작업한 가공품 정보를 등록하기위하여 **+** 버튼을 클릭합니다. 
<br/>
<br/>

![031](./img/031.png)
1. 수행한 가공품을 목록에서 선택합니다. 
    :::info
    해당 목록은 기술지원 접수 시 등록한 가공품 목록입니다. 
    가공품의 추가 등록이 필요한 경우, **개요** 탭으로 이동하여 추가합니다.
    :::
<br/>
<br/>

![032](./img/032.png)
:::warning
가공품을 선택해야만 내용 등록이 가능합니다.
:::
1. **완료여부**를 체크합니다. 
1. **가공일**을 선택합니다. 
1. 관련된 내용을 작성합니다. 
1. 가공 결과를 알 수 있는 자료를 추가합니다. 
1. **등록** 버튼을 클릭합니다. 
    :::info
    툴링 실적이 등록되면 영업 담당자 및 관련 담당자들에게 안내 메일이 발송됩니다.
    :::

### 툴링 및 샘플 - 완료
![033](./img/033.png)
<br/>툴링 및 샘플 작업이 완료되면 **완료** 버튼을 클릭합니다.

### 정산 - 1/2
:::warning
툴링 및 샘플 작업이 완료된 경우에만 정산 탭을 이용할 수 있습니다.
:::
<div><img src={Settlement1} width="70%" alt="034"/></div>

1. **수주여부**를 선택합니다.
1. **유무상** 구분을 선택합니다.
1. **청구 금액**을 입력합니다. 
1. **세금계산서 발행요청** 여부를 선택합니다. 
1. 세금계산서 발행 요청건의 경우 **발행 담당자**를 선택합니다. 
    :::info
    ![035](./img/035.png)
    1. 담당자를 선택하여 확인합니다.
    :::
1. **저장**을 클릭하여 정산 내용을 저장합니다. 

### 정산 - 2/2
<div><img src={Settlement2} width="70%" alt="036"/></div>

1. 세금계산서 **발행 여부**를 선택합니다. 
1. **S/O No.**를 입력합니다. 
1. **추가 내용**을 입력합니다. 
1. **저장**을 클릭하여 정산을 완료합니다. 
    :::info
    ![037](./img/037.png)
    정상적으로 저장이 된 경우 그림과같이 **완료**표시와 **업데이트날짜**가 표시됩니다.
    :::
